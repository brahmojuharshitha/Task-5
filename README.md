# Task 5 - Exploratory Data Analysis (EDA)

## Project
Retail Sales Data Exploration using Python.

## Dataset
`retail_sales.csv` contains 500 synthetic practice orders. The records are generated for learning and are not real business data.

## Files
- `Task5_Retail_Sales_EDA.ipynb` - Jupyter Notebook with the analysis code and observations.
- `Task5_EDA_Report.pdf` - PDF report with charts, findings and interview preparation.
- `retail_sales.csv` - Dataset used in the notebook.
- PNG files - Chart images used in the report.

## How to run
1. Keep the notebook and CSV file in the same folder.
2. Install the libraries listed in `requirements.txt`.
3. Open the notebook in Jupyter Notebook, JupyterLab or Google Colab.
4. Run the cells from top to bottom.

## Main steps
1. Load and inspect the dataset.
2. Check missing values and duplicates.
3. Fill missing category and region values.
4. Calculate descriptive statistics.
5. Plot category sales, region sales and sales distribution.
6. Explore units sold versus sales and view a correlation heatmap.
7. Summarize the findings.

## Note
The dataset is synthetic and intended only for practice. The results should not be represented as actual company performance.
